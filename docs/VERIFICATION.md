## 原生测试发现并处理的问题

1. AppData 同名目录在两个进程中可见内容不同；仅修改默认路径未解决。改用明确的
   项目共享私有存储并重新登记后通过。底层宿主/配置隔离机制尚未定性，没有更改安全权限。
2. 宿主只读长 JSON 的前 300 行，曾错误报告带隙未返回。核验完整工具 JSON 后确认
   字段存在；现将关键标量前置，并要求宿主读取完整相关字段。
3. 独立源码快照曾暴露图像解析对旧 ANN 模块的隐藏依赖。通用图像/标定检查已迁入
   轻量模块；旧入口兼容保留，精简快照重新测试通过。
4. 新增持久化 PDF 结果曾产生不稳定重复 ID，已改为内容核验去重并通过原有一致性回归。
