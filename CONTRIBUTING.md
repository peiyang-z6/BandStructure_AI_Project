# Contributing / 参与贡献

欢迎 Fork、Issue 和 Pull Request。Public + MIT 允许按许可证修改副本，
不代表任何人可以绕过审核直接写入维护者主分支。

Fork the repository, create a focused branch and submit a pull request with a
reproducible case, expected/actual behavior and regression tests. Do not include
credentials, personal documents, restricted papers, datasets or model weights.

    python -m pip install '.[documents,ocr,test]'
    python scripts/run_mcp_tests.py

Keep path and mesh semantics distinct. Unknown uncertainty stays unknown.
AI-generated labels cannot become independent human approval. Client templates,
CI definitions and successful imports are not completed scientific evaluations.

Do not post private input files or tokens when reporting security issues. Use an
available private contact channel for the repository owner instead.
