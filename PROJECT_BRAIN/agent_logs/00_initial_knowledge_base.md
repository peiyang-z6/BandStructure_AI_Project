# 🧠 初始知识库：能带物理与深度学习的交汇 (基于历史对话融合)

本文件由 AI Agent 提取自用户的前两次深度学习与计算材料学对话记录，作为后续所有 Agent 的“常识底座”。

## 一、 计算材料学基石 (来自 Chat 1)
### 1. 核心物理概念
- **能带图 ($E-k$)**：电子的地形图。纵轴能量($E$)，横轴动量/波矢($k$)。
- **费米能级 ($E_F$)**：电子填充的“水位线”（通常设为 0 eV）。穿过能带为金属，落在带隙为半导体/绝缘体。
- **带隙 ($E_g$)**：价带顶(VBM)与导带底(CBM)的能量差。
  - **直接带隙**：VBM与CBM同$k$点，垂直跃迁，发光效率高（LED/激光器）。
  - **间接带隙**：VBM与CBM异$k$点，需声子辅助，适合光伏/芯片（如Si）。
- **有效质量 ($m^*$)**：$1/m^* \propto \partial^2 E / \partial k^2$。曲率越大，电子越“轻”，迁移率越高。

### 2. 领域争议与局限 (AI 必须警惕的坑)
- **Mott 绝缘体**：强关联材料（如过渡金属氧化物）中，单电子近似(DFT)失效，预测为金属实为绝缘体。
- **Anderson 局域化**：无序体系中平移对称性破缺，传统 $E-k$ 能带概念失效。
- **DFT 带隙低估**：LDA/GGA 泛函系统性低估带隙 30%~50%。高精度需 HSE06 或 GW 近似。

### 3. 数据源与工具
- **数据库**：Materials Project (MP, 综合), OQMD (热力学), JARVIS (多保真度), C2DB (二维材料)。
- **开源项目**：CGCNN, MEGNet, ALIGNN (图神经网络预测性质)；DeepMD (神经势能面)。

## 二、 深度学习工程思维 (来自 Chat 2)
### 1. Keras 标准工作流
`数据准备 -> 模型搭建 -> 编译配置 -> 训练(Epoch/Batch) -> 评估 -> 部署`
- **防过拟合组合拳**：EarlyStopping, Dropout, L2正则化, ReduceLROnPlateau。

### 2. 专家的 5 个思维模式
1. **层次表征学习**：逐层抽象特征（局部->全局）。
2. **数据驱动迭代**：依赖实验反馈而非纯数学推导。
3. **优化与泛化权衡**：寻找容量与正则的临界点。
4. **模块化工程**：复用预训练权重与函数式 API。
5. **几何变换与流形解缠**：将高维纠缠数据映射为线性可分空间。

### 3. 领域争议 (AI 设计模型时的考量)
- **黑盒 vs 可解释性**：在科学计算中，纯黑盒不可接受，需引入物理约束(PINN)或注意力机制。
- **大数据依赖 vs 小样本**：材料学高精度数据稀缺，需依赖**自监督学习(SSL)**或**迁移学习**。
- **端到端 vs 特征工程**：在能带预测中，完全端到端可能忽略对称性，需人工编码高对称点掩码或曲率特征。

## 三、 交叉点：本项目的核心挑战
将能带视为**多变量时间序列**或**图结构**，而非图像。
- **输入**：晶体结构图 / 原子坐标 / 元素电负性。
- **输出**：$E(k)$ 序列曲线。
- **Loss 设计**：不仅计算 MSE，还需加入**曲率惩罚项**（保证有效质量物理意义）和**对称性惩罚项**。
